OmniFlow

Multi-Agent DAG Workflow Desktop Tool — Orchestrate AI agents to retrieve, summarize, generate, and verify, all in one place.

Overview

OmniFlow is a desktop application that orchestrates multiple AI agents to streamline information processing, content generation, and decision-making tasks. Instead of switching between multiple tools, you complete complex workflows in one place.

🤖 Multi-Agent Collaboration

5 specialized agents work together under a DAG execution engine. Orchestrator decomposes tasks, agents execute in parallel or sequence.

📊 DAG Visualization

Real-time ReactFlow visualization shows exactly which agent is doing what, with dependency edges and status indicators.

🔌 Multi-Model Support

OpenAI, Anthropic, Google Gemini, DeepSeek, Ollama (local), OpenRouter — bring your own API keys.

🧩 Skill System

OpenCode-compatible SKILL.md format. Built-in skills for contract review, meeting minutes, and web search.

🖥️ Desktop + CLI

Full Electron desktop app with chat UI, or use the command-line interface for automation and scripting.

🔄 Feedback Loops

Verifier agent checks output quality and triggers up to 3 rounds of iterative improvement through the Generator.

Quick Start

Desktop

1

Launch OmniFlow

Open the app from the Start Menu or run OmniFlow.exe directly.

2

Configure a Model

Click the gear icon ⚙ in the bottom-right status bar. Select a provider (e.g. OpenAI), choose a model (e.g. GPT-4o), and enter your API key.

3

Select Working Directory

Click the folder in the left panel to choose a working directory. The file tree allows agents to read local files.

4

Enter a Task

Type your task in the chat input. Try: 整理合同风险点，生成一份评估报告

5

Watch the DAG

The right panel shows the DAG workflow in real-time: Orchestrator → Retriever → Summarizer → Generator → Verifier.

CLI

# Configure a model first
omniflow config add openai gpt-4o sk-your-api-key

# Run a task
omniflow run "Summarize the quarterly report"

# Interactive REPL
omniflow repl

Architecture

OmniFlow uses a four-layer architecture:

LayerTechnologyRole
UIReact 18, Tailwind CSS, ReactFlow v12Chat panel, DAG visualization, file tree, settings
OrchestrationDAG Engine (TypeScript)Task decomposition, dependency resolution, parallel/sequential scheduling
CapabilityLLM Router, Skill RegistryMulti-provider LLM routing, skill loading and matching
PlatformElectron, Node.jsFile system access, IPC, configuration persistence

The Orchestrator agent decomposes user tasks into a Directed Acyclic Graph (DAG) of subtasks. Each subtask is assigned to the most appropriate agent. The DAG engine resolves dependencies and executes ready nodes in parallel.

Agent System

OmniFlow has 5 specialized agents:

AgentBadgeRoleInputOutput
Orchestrator 编排者 Understand intent, decompose into DAG Natural language DAG task graph
Retriever 检索者 Search files, web, knowledge bases Query description Structured results
Summarizer 归纳者 Merge, refine, deduplicate info Multi-source data Refined summary
Generator 生成者 Write reports, emails, code, documents Structured material + instructions Generated content
Verifier 校验者 Check accuracy, completeness, consistency Content to verify Verification report + suggestions

DAG Workflow

Tasks are decomposed into a Directed Acyclic Graph. Each node is a subtask assigned to one agent. Edges represent data dependencies.

Example Flow

User says: "Analyze the risks in this contract and generate an assessment report."

         ┌──────────┐
         │Orchestrator│ ← Understands intent, builds DAG
         └─────┬────┘
               │
       ┌───────┼───────┐
       ▼       ▼       ▼
  ┌────────┐┌────────┐┌────────┐
  │Retriever││Retriever││Retriever│ ← Read contract + Search laws
  └───┬────┘└───┬────┘└───┬────┘
      └────┬────┴────┬────┘
           ▼         ▼
      ┌─────────┐┌──────────┐
      │Summarizer││ Generator│ ← Synthesize findings + Draft report
      └────┬─────┘└─────┬────┘
           └──────┬─────┘
                  ▼
            ┌──────────┐    fail+feedback
            │ Verifier │──────────────────→ Generator (retry up to 3x)
            └─────┬────┘←──────────────────
                  │ pass
                  ▼
               Output
The Verifier → Generator loop enables automatic quality improvement. If the score is below threshold, feedback is passed back to the Generator for another round.

Configuration

Desktop

  2. Choose a provider and model from the preset list
  3. Enter your API key
  4. Optionally set a custom base URL (for proxies or self-hosted)
  5. Click Add Model Configuration

FAQ

Is my API key stored securely?

API keys are stored locally in ~/.omniflow/settings.json. They are only transmitted to the LLM provider endpoint you configure. Keys are never sent to our servers (we don't have any).

Can I use local models without internet?

Yes. Install Ollama, pull a model (e.g. ollama pull qwen3:14b), then add it in OmniFlow with any placeholder API key. All inference runs locally.

How does the feedback loop work?

When a Verifier agent scores the output below 6/10, it generates feedback. The DAG engine passes this feedback back to the Generator and re-runs it. This happens up to 3 times.

What file formats can agents read?

Agents can read any text-based file in your working directory through the file tree panel. For binary files (PDF, DOCX), you would need a skill with appropriate parsing scripts.

Can I add custom agents?

Currently, the 5 core agents are built-in. However, you can heavily customize their behavior through the skill system — each skill injects a specialized system prompt into its target agent.

Does the CLI work on macOS/Linux?

Yes. The CLI is a pure Node.js application and runs on any platform with Node.js 18+. Desktop builds for macOS and Linux are configured but not yet pre-built.
